Hospital Management

Модуль для автоматизації обліку лікарні

Можливості модуля

  • Управління лікарями та їх категоріями
  • Ведення пацієнтів та історії лікарів
  • Запис та контроль візитів
  • Діагнози та медична інформація
  • Аналітика (pivot, calendar)

Основні функції

  • Автоматичне призначення лікаря
  • Контроль інтернів та менторів
  • Перевірка унікальності даних
  • Система історії лікарів
